## ✨ Sobre o projeto

Este projeto foi desenvolvido com o objetivo de criar uma landing page moderna e responsiva, 
utilizando uma paleta suave e elementos minimalistas para transmitir organização, tecnologia e sofisticação.

O layout foi pensado para oferecer uma experiência agradável tanto em desktop quanto em dispositivos móveis.


## 🎨 Layout

O design utiliza:

- Tons claros e suaves
- Efeito glassmorphism
- Cards modernos
- Hero section 
- Menu responsivo
- Animações suaves
- Layout totalmente responsivo

## 📱 Responsividade

O projeto possui responsividade para:

- 💻 Desktop
- 📱 Mobile
- 📲 Tablets

Incluindo:
- Menu hamburguer animado
- Reorganização automática de elementos
- Ajuste de imagens e textos
- Grid responsivo
